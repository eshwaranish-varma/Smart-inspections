From inspection notes to evaluation scores

A simple view of how the backend checks that each draft observation stays tied to your source text.

Start

Inputs

Raw notes (full inspection text) and the AI draft (observations, evidence bullets, CFR citations).

Step 1

Quality checks

Each observation is checked for a complete structure (narrative, evidence, citation) and whether the CFR reference matches Title 21 data where applicable.

Step 2

Grounding — linking evidence to the notes

For every evidence bullet, the system asks: “Can we find this in the original notes?”

Two ways a bullet can pass
Text match Same wording appears in the notes (with simple normalization).
Meaning match Notes are split into short passages; each passage and the bullet are turned into vectors. If the closest match is above a similarity threshold, it counts as grounded.
Step 3

Scores for the dashboard

Results roll up into metrics partners see: how many bullets are supported, how strongly the observation wording overlaps the source, and combined “overall” quality — plus optional OCR alignment when a reference transcript is provided.

Output

Evaluation dashboard & API validation

Stored scores for trending and the same grounding logic used to flag weak evidence on live responses.

Smart Inspection — internal grounding flow (business summary). Technical defaults and modes are configurable in the backend.
